# 拾事 v1.1 规划：发布硬化、协作与规模化

> 状态：设计与实施并行
> 日期：2026-10-22
> 目标：在保持 local-first 语义和现有 P0-P3 能力的前提下，完成第 1-5 项计划。

## 交付原则

1. **先设计后编码**：每项先有边界、数据模型、API/UX 契约、验收标准。
2. **不破坏本地优先**：所有日常操作先写本机；网络失败不得阻塞录入。
3. **不静默覆盖**：云同步、共享合并、账号切换都必须显式确认。
4. **可回滚**：数据库迁移只增不删；客户端保留导入/导出。
5. **可验证**：每一项都有自动化测试或明确的环境边界说明。

## 分阶段实施

### Phase A：发布硬化（第 1 项）

- 版本基线、tag、CI 全绿。
- `/metrics` 与 request id。
- 生产 smoke 脚本：`healthz`、`readyz`、登录、同步、导出。
- 生产 runbook 增补告警与容量建议。

### Phase B：同步/账号与规模化（第 2、3 项）

- 拒绝操作详情与诊断包。
- 云端导出。
- 多账号本地隔离。
- Web Push 订阅与到期提醒。
- keyset 分页和 100k 压力测试。

### Phase C：产品能力（第 4 项）

- 标签、筛选、保存视图。
- 日历视图、ICS 导入/导出。
- 自然语言快速添加。
- 模板、每周回顾。
- 共享清单 v1（只读/编辑成员，见 04）。

### Phase D：质量门禁（第 5 项）

- 同步/重复规则 property 测试。
- API fuzz/边界测试。
- SQLite/IndexedDB/PostgreSQL 迁移测试。
- 备份恢复 CI、SBOM、性能预算回归。

## 成功标准

- `pnpm check` 通过。
- Playwright 回归/axe 全部通过。
- Rust workspace clippy/test 通过。
- PostgreSQL 集成测试通过。
- 10k 性能不退化，100k 分页可交互。
- 每项功能在 `docs/roadmap-v2/` 有对应设计与验收记录。

- ✅ `/metrics`、`X-Request-Id`、JSON 访问日志、生产 smoke、运维 runbook。
- ✅ 拒绝操作详情/单条回滚、云端备份、诊断包、Web 多账号隔离、Web Push 订阅与测试接口。
- ✅ 100k 全量列表加载与虚拟滚动、性能预算脚本、PostgreSQL 同步集成测试。
- ✅ 标签/筛选/保存视图、日历视图、ICS 导入导出、自然语言快速添加、模板、每周回顾。
- ✅ 共享清单在线 v1：独立服务端表/API、owner/editor/viewer、revision 冲突、成员邀请、15s 轮询。
- ✅ property tests、IndexedDB/SQLite 迁移覆盖、PostgreSQL 集成回归、SBOM、性能预算门禁。
- ⚠️ 共享清单 Web 端尚未做本地共享 outbox/离线编辑；多账号隔离只在 Web IndexedDB 生效。
- ⚠️ Web Push 未连接真实 FCM/浏览器推送服务；native 未接入共享清单和 Web Push。
- ⚠️ 真实 Android/iOS 构建、真实 SMTP、公网 Caddy 证书、100k 滚动 FPS 未在本机验收。

## 非目标

- 不实现端到端加密（需独立安全设计，避免伪安全）。
- 不在本机验证 Android/iOS 真机安装与签名。
- 不引入外部实时协作服务；共享清单第一版采用轮询 revision。
