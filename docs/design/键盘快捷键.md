# 键盘快捷键

> 全局快捷键、任务操作快捷键、命令面板的完整设计。

---

## 1. 快捷键分层

快捷键分为三个层级：

| 层级 | 作用范围 | 示例 |
|------|---------|------|
| **全局快捷键** | 应用内任意页面 | 新建任务、搜索、设置 |
| **列表快捷键** | 任务列表页面 | 切换筛选、完成、删除 |
| **编辑快捷键** | 输入框 / 任务详情 | 保存、取消、清空 |
| **命令面板** | 全局 | 任意操作的模糊搜索 |

---

## 2. 全局快捷键

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `N` | 新建任务 | 在当前列表快速创建任务（聚焦输入框） |
| `Cmd/Ctrl + K` | 打开命令面板 | 模糊搜索所有操作 |
| `Cmd/Ctrl + /` | 显示快捷键列表 | 弹出快捷键帮助弹窗 |
| `Cmd/Ctrl + Shift + F` | 全局搜索 | 聚焦搜索框 |
| `Cmd/Ctrl + ,` | 打开设置 | 打开 SettingsDrawer |
| `Esc` | 关闭抽屉/面板 | 关闭 TaskDetailDrawer / SettingsDrawer / 命令面板 |

### 6.3 实现

```typescript
function CommandPalette({ isOpen, onClose }: Props) {
  const [query, setQuery] = useState('');
  const inputRef = useRef<HTMLInputElement>(null);

  const commands = useMemo(() => [
    { id: 'new-task', label: '新建任务', icon: <PlusIcon />, shortcut: 'N', action: () => { onClose(); openQuickAdd(); } },
    { id: 'search', label: '搜索', icon: <SearchIcon />, shortcut: 'Ctrl+Shift+F', action: () => { onClose(); focusSearch(); } },
    // ...更多命令
  ], []);

  const filtered = useMemo(() => {
    if (!query) return commands;
    return commands.filter(cmd =>
      cmd.label.toLowerCase().includes(query.toLowerCase()) ||
      cmd.id.toLowerCase().includes(query.toLowerCase())
    );
  }, [query, commands]);

  // 键盘导航
  const [selectedIndex, setSelectedIndex] = useState(0);

  useEffect(() => {
    setSelectedIndex(0);
  }, [query]);

  return (
    <div className="command-palette">
      <input
        ref={inputRef}
        value={query}
        onChange={e => setQuery(e.target.value)}
        onKeyDown={e => {
          if (e.key === 'ArrowDown') setSelectedIndex(i => Math.min(i + 1, filtered.length - 1));
          if (e.key === 'ArrowUp') setSelectedIndex(i => Math.max(i - 1, 0));
          if (e.key === 'Enter') filtered[selectedIndex]?.action();
          if (e.key === 'Escape') onClose();
        }}
        placeholder="输入命令或搜索..."
        autoFocus
      />
      <div className="command-list">
        {filtered.map((cmd, i) => (
          <div key={cmd.id} className={i === selectedIndex ? 'selected' : ''} onClick={cmd.action}>
            {cmd.icon} {cmd.label}
            {cmd.shortcut && <kbd>{cmd.shortcut}</kbd>}
          </div>
        ))}
      </div>
    </div>
  );
}
```

## 7. 全局快捷键监听

```typescript
useEffect(() => {
  function handleKeyDown(e: KeyboardEvent) {
    // 忽略输入框内的按键（除了特定快捷键）
    const isInputFocused = ['INPUT', 'TEXTAREA'].includes((e.target as HTMLElement).tagName);

    // 全局快捷键（输入框内也生效）
    if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
      e.preventDefault();
      openCommandPalette();
      return;
    }

    if ((e.metaKey || e.ctrlKey) && e.key === '/') {
      e.preventDefault();
      showShortcutsHelp();
      return;
    }

    // 仅在非输入状态时生效的快捷键
    if (isInputFocused) return;

    switch (e.key) {
      case 'n':
      case 'N':
        if (!e.metaKey && !e.ctrlKey) {
          openQuickAdd();
        }
        break;
      // ...
    }
  }

  window.addEventListener('keydown', handleKeyDown);
  return () => window.removeEventListener('keydown', handleKeyDown);
}, []);
```

## 8. 各平台快捷键差异

| 问题 | 解决方案 |
|------|---------|
| macOS `Cmd` vs Windows `Ctrl` | 同时支持，检测 `e.metaKey` 和 `e.ctrlKey` |
| 小程序无键盘 | 快捷键不可用，仅保留命令面板入口（通过点击按钮触发） |
| 浏览器扩展快捷键被占用 | `Cmd+Shift+U` 以上的组合通常未被占用 |
| React Native 无原生键盘事件 | 使用 `TextInput` 的 `onKeyPress` 或 `react-native-hotkeys` |

### 8.1 浏览器扩展快捷键（manifest.json）
