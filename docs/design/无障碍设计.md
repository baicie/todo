# 无障碍设计

> 确保应用对所有用户可用，包括视力障碍、运动障碍和认知障碍用户。遵循 WCAG 2.1 AA 标准。

---

## 1. 目标与标准

| 标准 | 级别 | 说明 |
|------|------|------|
| WCAG 2.1 | AA | 最低合规目标 |
| WCAG 2.1 | AAA | 高级特性目标 |
| WAI-ARIA | 1.2 | 动态内容无障碍支持 |
| EN 301 549 | — | 欧盟政府采购标准 |

### 1.1 四项核心原则（POUR）

| 原则 | 说明 | 实现要求 |
|------|------|---------|
| **可感知** (Perceivable) | 信息和 UI 组件必须以用户可感知的方式呈现 | 文字替代、足够对比度、字幕 |
| **可操作** (Operable) | UI 组件和导航必须可操作 | 键盘支持、足够时间、无闪烁 |
| **可理解** (Understandable) | 信息和 UI 操作必须可理解 | 清晰语言、一致导航、错误建议 |
| **健壮** (Robust) | 内容必须可被各种用户代理可靠解读 | 语义 HTML、ARIA 正确使用 |

## 3. 键盘可访问性

### 3.1 焦点管理

| 要求 | 实现 |
|------|------|
| 所有交互元素可 Tab 聚焦 | 使用 `<button>`、`<a>` 而非 `<div onClick>` |
| 焦点顺序符合逻辑 | DOM 顺序与视觉顺序一致 |
| 焦点可见 | 使用 `outline` 或自定义焦点样式 |
| 陷阱焦点 | 模态框/抽屉打开时，焦点限制在内部 |
| 焦点返回 | 关闭弹窗时，焦点返回到触发元素 |

```css
/* 焦点样式 */
:focus-visible {
  outline: 2px solid var(--theme-primary);
  outline-offset: 2px;
}

/* 移除默认焦点环，改用更好的样式 */
:focus:not(:focus-visible) {
  outline: none;
}
```

### 3.2 抽屉焦点陷阱

```typescript
function TaskDetailDrawer({ isOpen, onClose }: Props) {
  const drawerRef = useRef<HTMLDivElement>(null);
  const previousFocusRef = useRef<HTMLElement | null>(null);

  useEffect(() => {
    if (isOpen) {
      // 保存之前焦点
      previousFocusRef.current = document.activeElement as HTMLElement;

      // 聚焦到抽屉第一個可交互元素
      const firstFocusable = drawerRef.current?.querySelector<HTMLElement>(
        'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
      );
      firstFocusable?.focus();
    } else {
      // 恢复焦点
      previousFocusRef.current?.focus();
    }
  }, [isOpen]);

  // ESC 关闭
  useEffect(() => {
    const handleEsc = (e: KeyboardEvent) => {
      if (e.key === 'Escape' && isOpen) {
        onClose();
      }
    };
    window.addEventListener('keydown', handleEsc);
    return () => window.removeEventListener('keydown', handleEsc);
  }, [isOpen, onClose]);

  return (
    <div
      ref={drawerRef}
      role="dialog"
      aria-modal="true"
      aria-labelledby="drawer-title"
      aria-describedby="drawer-description"
    >
      {/* 内容 */}
    </div>
  );
}
```

### 3.3 任务列表键盘导航

```typescript
function TaskList() {
  const [focusedIndex, setFocusedIndex] = useState(-1);

  return (
    <div
      role="listbox"
      aria-label="任务列表"
      onKeyDown={(e) => {
        if (e.key === 'ArrowDown') {
          e.preventDefault();
          setFocusedIndex(i => Math.min(i + 1, tasks.length - 1));
        }
        if (e.key === 'ArrowUp') {
          e.preventDefault();
          setFocusedIndex(i => Math.max(i - 1, 0));
        }
        if (e.key === 'Enter') {
          openTaskDetail(tasks[focusedIndex]);
        }
        if (e.key === ' ') {
          e.preventDefault();
          toggleComplete(tasks[focusedIndex]);
        }
      }}
    >
      {tasks.map((task, i) => (
        <div
          key={task.id}
          role="option"
          aria-selected={i === focusedIndex}
          tabIndex={i === focusedIndex ? 0 : -1}
          className={i === focusedIndex ? 'focused' : ''}
        >
          {/* 任务内容 */}
        </div>
      ))}
    </div>
  );
}
```

## 4. ARIA 属性规范

### 4.1 组件 ARIA 模式

| 组件 | ARIA 属性 |
|------|---------|
| 按钮（无文字） | `aria-label="关闭"` |
| 图标按钮 | `aria-label="标记为重要"` |
| 复选框 | `<input type="checkbox">`（隐式 ARIA） |
| 抽屉/弹窗 | `role="dialog"` `aria-modal="true"` `aria-labelledby` |
| 折叠面板 | `role="region"` `aria-expanded` `aria-controls` |
| 选项卡 | `role="tablist"` `role="tab"` `aria-selected` `aria-controls` |
| 工具提示 | `role="tooltip"` `aria-describedby` |
| 下拉菜单 | `role="menu"` `role="menuitem"` |
| 加载状态 | `aria-busy="true"` `aria-live="polite"` |
| 空状态 | `aria-label="暂无任务"` |

### 4.2 清单切换（Switch）

```html
<!-- 标记任务为重要 -->
<button
  type="button"
  role="switch"
  aria-checked={task.isImportant}
  aria-label="标记为重要"
  className="star-button"
>
  {task.isImportant ? <StarFilledIcon /> : <StarIcon />}
</button>
```

### 4.3 进度指示器

```html
<div
  role="progressbar"
  aria-valuenow={completedCount}
  aria-valuemin={0}
  aria-valuemax={totalCount}
  aria-label="任务完成进度"
>
  {completedCount} / {totalCount}
</div>
```

## 5. 颜色与对比度

### 5.1 对比度要求

| 内容类型 | 最低对比度（AA） | 推荐对比度（AAA） |
|---------|----------------|-----------------|
| 正常文本（< 18px） | 4.5:1 | 7:1 |
| 大文本（≥ 18px / ≥ 14px 加粗） | 3:1 | 4.5:1 |
| UI 组件和图形 | 3:1 | 3:1 |

### 5.2 当前配色检查

```
主色调 #3b82f6（蓝色）:

白底上的蓝色文字 → 对比度 ~4.16:1 ✅ (接近 AA)
灰色背景上的蓝色文字 → 对比度需实测

分类颜色:
🔵 蓝色: #3b82f6 → 需确保文字对比度
🔴 红色: #ef4444 → 需确保文字对比度
🟢 绿色: #22c55e → 需确保文字对比度
🟠 橙色: #f59e0b → 需确保文字对比度

建议：分类标签使用深色背景 + 浅色文字，而非浅色背景 + 深色文字
```

### 5.3 暗色模式配色

| 元素 | 浅色模式 | 暗色模式 |
|------|---------|---------|
| 背景 | `#f8fafc` | `#0f172a` |
| 文本 | `#111827` | `#f1f5f9` |
| 次要文本 | `#6b7280` | `#94a3b8` |
| 主色调 | `#3b82f6` | `#60a5fa` |
| 边框 | `#e2e8f0` | `#334155` |

### 5.4 不依赖颜色的信息传达

| 信息 | 颜色表示 | 额外传达方式 |
|------|---------|-----------|
| 重要任务 | 黄色星标 | `aria-label="重要"` |
| 完成任务 | 灰色 + 删除线 | `aria-label="已完成"` |
| 已过期 | 红色文字 | 日期旁的图标 |
| 今日任务 | 蓝色背景 | 文字标注 |
| 空列表 | — | 空状态图标 + 提示文案 |

## 8. 动画与运动

### 8.1 减少动画偏好

```css
/* 尊重用户减少动画偏好 */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

### 8.2 设置选项

在 Settings 中提供「减少动画」开关：

```typescript
// 检测系统偏好
const prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

// 用户手动覆盖
const reduceMotion = localStorage.getItem('reduce-motion') === 'true';
```

## 10. 移动端无障碍

| 问题 | 解决方案 |
|------|---------|
| 触摸目标过小 | 最小触摸区域 44×44 px |
| 双击缩放 | `<meta name="viewport" content="width=device-width, initial-scale=1">` |
| 长按菜单 | 使用 `oncontextmenu` 但不依赖右键 |
| 方向锁定 | 不要求特定屏幕方向 |
| 语音控制 | 支持 Tap 聚焦（Voice Access） |
