# 通知系统

> 任务到期提醒、重复任务触发、以及各平台的推送实现。

---

## 1. 通知类型

本应用的通知分为以下几类：

| 类型 | 触发条件 | 示例 |
|------|---------|------|
| **到期提醒** | 到达 `reminderDate` 时间点 | "下午 3 点：完成项目报告" |
| **重复任务** | 重复任务完成或到期时 | "每周一：团队周会" |
| **系统通知** | 后端主动推送（多设备场景） | "你在另一台设备修改了任务 X" |

## 3. 到期提醒流程

### 3.1 定时检查机制

```typescript
class NotificationService {
  private checkInterval: number = 60000; // 每分钟检查一次

  start() {
    // 页面激活时立即检查一次
    this.checkReminders();

    // 设置定时检查
    this.intervalId = setInterval(() => {
      this.checkReminders();
    }, this.checkInterval);
  }

  stop() {
    clearInterval(this.intervalId);
  }

  async checkReminders() {
    const now = new Date();
    const tasks = await storage.tasks.getTasks();

    for (const task of tasks) {
      if (task.reminderDate && !task.isCompleted) {
        const reminder = new Date(task.reminderDate);

        // 触发条件：已到提醒时间，且未在过去 5 分钟内通知过
        if (reminder <= now && now - reminder < 5 * 60 * 1000) {
          const notifiedKey = `notified_${task.id}`;
          if (!localStorage.getItem(notifiedKey)) {
            await this.showNotification(task);
            localStorage.setItem(notifiedKey, 'true');
          }
        }
      }
    }
  }

  async showNotification(task: Task) {
    if (!('Notification' in window)) return;

    const permission = await Notification.requestPermission();
    if (permission !== 'granted') return;

    new Notification(task.title, {
      body: task.description || '任务已到期',
      icon: '/icons/icon-192.png',
      tag: task.id, // 相同 tag 不会重复弹窗
      data: { taskId: task.id },
    });
  }
}
```

### 3.2 后台标签（Background Tag）

对于 `reminderDate`，用户可以设置预设快捷时间：

| 预设 | 计算方式 |
|------|---------|
| 今天晚些时候 | 当天 17:00 |
| 明天 | 明天 09:00 |
| 下周 | 7 天后 09:00 |
| 自定义日期 | 用户选择的日期 + 09:00 |

## 4. 重复任务逻辑

### 4.1 重复模式

```typescript
type RepeatPattern = 'daily' | 'weekly' | 'monthly' | 'yearly' | 'weekdays' | 'custom' | null;

interface CustomRepeat {
  interval: number;      // 间隔数量
  unit: 'day' | 'week' | 'month' | 'year';
  endDate?: string;     // 可选的结束日期
}
```

### 4.2 重复任务触发

当一个重复任务被标记为完成（`isCompleted = true`）时，自动创建下一个周期的任务：

```typescript
async function handleCompleteTask(task: Task) {
  await storage.tasks.updateTask(task.id, { isCompleted: true });

  // 如果是重复任务，自动创建下一个
  if (task.repeatPattern) {
    const nextDueDate = calculateNextDueDate(task.dueDate!, task.repeatPattern);

    await storage.tasks.createTask({
      title: task.title,
      description: task.description || undefined,
      dueDate: nextDueDate,
      repeatPattern: task.repeatPattern,
      listId: task.listId || undefined,
    });
  }
}

function calculateNextDueDate(currentDate: string, pattern: RepeatPattern): string {
  const date = new Date(currentDate);

  switch (pattern) {
    case 'daily':
      date.setDate(date.getDate() + 1);
      break;
    case 'weekly':
      date.setDate(date.getDate() + 7);
      break;
    case 'monthly':
      date.setMonth(date.getMonth() + 1);
      break;
    case 'yearly':
      date.setFullYear(date.getFullYear() + 1);
      break;
    case 'weekdays':
      // 周一至周五
      do { date.setDate(date.getDate() + 1); }
      while (date.getDay() === 0 || date.getDay() === 6);
      break;
  }

  return date.toISOString();
}
```

### 4.3 过期重复任务的处理

当重复任务错过到期日期后再次标记完成，应跳到**下一个周期**而非当天：

```
昨天应完成 → 今天标记完成 → 创建明天的周期任务
(而非创建今天已过期的任务)
```

## 5. 浏览器原生通知

### 5.1 权限申请

```typescript
async function requestNotificationPermission(): Promise<boolean> {
  if (!('Notification' in window)) {
    console.warn('当前浏览器不支持通知');
    return false;
  }

  if (Notification.permission === 'granted') {
    return true;
  }

  if (Notification.permission !== 'denied') {
    const permission = await Notification.requestPermission();
    return permission === 'granted';
  }

  return false;
}
```

**申请时机**：用户在任务详情中首次设置提醒时，弹出权限请求。不在首次打开应用时强制申请。

### 5.2 通知点击处理

```typescript
self.addEventListener('notificationclick', (event) => {
  event.notification.close();

  const taskId = event.notification.data?.taskId;
  if (taskId) {
    // 打开应用并导航到该任务
    clients.openWindow(`/tasks/my-day?highlight=${taskId}`);
  }
});
```

## 6. 各平台通知实现

### 6.1 Web（浏览器通知）

| 方案 | 说明 | 离线支持 |
|------|------|---------|
| 浏览器原生 Notification API | 无需额外依赖 | ❌ 需要页面激活 |
| Service Worker + Web Push | 离线时由服务端推送 | ✅ 完全支持 |

**当前阶段**：使用浏览器原生 Notification API，在页面激活时定时检查。

**未来升级**：迁移到 Web Push API，支持离线推送（需要后端实现 FCM/APNs 桥接）。

### 6.2 Browser Extension

```typescript
// background.ts
chrome.notifications.create({
  type: 'basic',
  iconUrl: 'icons/icon-192.png',
  title: task.title,
  message: task.description || '任务已到期',
  priority: 2,
  tag: task.id,
});
```

扩展的通知能力比网页更强：**即使浏览器关闭也能收到通知**（由 Background Script 驱动）。

### 6.3 Desktop（Tauri）

Tauri 通过 Rust 端的 `tauri-plugin-notification` 实现系统通知：

```rust
// src-tauri/src/lib.rs
use tauri_plugin_notification::NotificationExt;

#[tauri::command]
fn send_notification(app: AppHandle, title: &str, body: &str) -> Result<(), String> {
    app.notification()
        .builder()
        .title(title)
        .body(body)
        .show()
        .map_err(|e| e.to_string())?;
    Ok(())
}
```

```typescript
// 前端调用
import { invoke } from '@tauri-apps/api/core';
await invoke('send_notification', { title: task.title, body: '任务已到期' });
```

桌面端通知支持系统托盘图标徽章（未完成任务数）。

### 6.4 Mobile（React Native / Expo）

使用 `expo-notifications`：

```typescript
import * as Notifications from 'expo-notifications';

await Notifications.scheduleNotificationAsync({
  content: {
    title: task.title,
    body: task.description || '任务已到期',
    data: { taskId: task.id },
  },
  trigger: {
    type: Notifications.SchedulableTriggerInputTypes.DATE,
    date: new Date(task.reminderDate!),
  },
});
```

需要申请权限：

```typescript
const { status } = await Notifications.requestPermissionsAsync();
// ios 还需要请求 POUND_PRESENTMENT
```

## 7. 降级策略

当通知权限被拒绝时：

| 平台 | 降级方案 |
|------|---------|
| Web | 在应用内显示通知气泡（Toast），不依赖系统通知 |
| Browser Ext | 降级到 Content Script 注入的通知 UI |
| Desktop | 降级到系统托盘图标 + 应用内通知 |
| Mobile | 降级到 In-App 通知 + 应用角标 |

## 8. 设置选项

在 Settings 页面提供以下通知配置：

| 选项 | 默认值 | 说明 |
|------|-------|------|
| 启用通知 | true | 全局开关 |
| 提醒时间提前量 | 0 分钟 | 到期前多久提醒（0/5/10/15/30 分钟） |
| 重复任务通知 | true | 重复任务到期时是否通知 |
| 声音 | true | 通知是否带声音 |
| 仅重要任务 | false | 仅对标记为重要的任务发送通知 |

---

## 9. 注意事项

1. **电量优化**：移动端定时检查需注意后台运行限制，优先使用系统级定时器（AlarmManager / Background Fetch）
2. **权限拒绝处理**：通知权限被拒后不频繁申请（仅在用户主动触发提醒设置时申请一次）
3. **重复任务通知去重**：使用 `task.id` 作为 Notification tag，同一任务不会同时出现两个通知
4. **时区处理**：所有时间存储为 UTC，渲染时转换为用户本地时区
