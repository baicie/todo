# 认证流程

> 游客模式、登录注册、账号关联、存储模式切换的完整认证设计。

---

## 1. 认证模式概述

本应用支持**两种使用模式**，互不冲突：

| 模式 | 说明 | 数据存储 | 是否需要后端 |
|------|------|---------|------------|
| **游客模式** | 不登录直接使用，数据存储在本地 | IndexedDB | 否 |
| **账号模式** | 登录后使用，数据同步到远程 | IndexedDB + REST API | 是 |

用户可以随时在设置中切换模式。游客积累的本地数据在登录时提供迁移选项。

## 3. 游客模式

### 3.1 特性

- 无需注册，下载即用
- 所有数据存储在本地 IndexedDB
- 支持完整的功能（任务、清单、提醒等）
- 不支持多设备同步、不支持协作

### 3.2 游客模式限制

| 功能 | 游客模式 | 账号模式 |
|------|---------|---------|
| 任务管理 | ✅ 完整 | ✅ 完整 |
| 清单管理 | ✅ 完整 | ✅ 完整 |
| 文件上传 | ✅ 本地存储 | ✅ 远程存储 |
| 多设备同步 | ❌ | ✅ |
| 协作共享 | ❌ | 规划中 |
| 账号安全（密码修改等） | N/A | ✅ |

### 3.3 游客状态下的 UI 引导

当用户处于游客模式时，在以下位置显示引导：

- **Header 右侧**：显示"登录以同步"按钮（点击跳转登录页）
- **Settings 页面**：在账号区域显示"登录账号"/"创建账号"入口
- **首次使用**：不弹强制注册，但显示一次性的功能介绍横幅

### 4.3 密码要求

| 要求 | 规则 |
|------|------|
| 最小长度 | 6 个字符 |
| 建议 | 至少 8 字符，包含数字和字母 |

> 注：当前后端 `User` 实体有 `age` 字段，注册流程中是否需要收集年龄需确认业务需求。

## 5. 认证存储接口

### 5.1 IAuthStorage 接口

```typescript
interface IAuthStorage {
  readonly mode: 'local' | 'remote';
  login(email: string, password: string): Promise<AuthResult>;
  register(name: string, email: string, password: string): Promise<AuthResult>;
  getProfile(): Promise<User>;
  getStoredUser(): User | null;
  getStoredToken(): string | null;
  setAuth(result: AuthResult): void;
  clearAuth(): void;
}
```

### 5.2 LocalAuthStorage 实现

```typescript
class LocalAuthStorage implements IAuthStorage {
  readonly mode: 'local';

  login(_email: string, _password: string): Promise<AuthResult> {
    // 游客模式下登录操作无意义，生成一个本地虚拟用户
    const localUser: User = {
      id: 0,
      name: 'Local User',
      email: '',
      age: 0,
      createdAt: new Date().toISOString(),
    };
    const result: AuthResult = { user: localUser, token: 'local-token' };
    this.setAuth(result);
    return Promise.resolve(result);
  }

  register(name: string, email: string, _password: string): Promise<AuthResult> {
    // 同上，生成虚拟用户
    const localUser: User = { id: 0, name, email, age: 0, createdAt: new Date().toISOString() };
    const result: AuthResult = { user: localUser, token: 'local-token' };
    this.setAuth(result);
    return Promise.resolve(result);
  }

  getStoredUser(): User | null { /* 从 localStorage 读取 */ }
  getStoredToken(): string | null { /* 从 localStorage 读取 */ }
  setAuth(result: AuthResult): void { /* 写入 localStorage */ }
  clearAuth(): void { /* 清除 localStorage */ }
}
```

### 5.3 RemoteAuthStorage 实现

```typescript
class RemoteAuthStorage implements IAuthStorage {
  readonly mode: 'remote';

  async login(email: string, password: string): Promise<AuthResult> {
    const response = await this.api.post('/auth/login', { email, password });
    const result: AuthResult = response.data;
    this.setAuth(result);
    return result;
  }

  async register(name: string, email: string, password: string): Promise<AuthResult> {
    const response = await this.api.post('/auth/register', { name, email, password });
    return response.data;
  }

  async getProfile(): Promise<User> {
    const response = await this.api.get('/auth/profile');
    return response.data;
  }

  getStoredUser(): User | null { /* 从内存 + localStorage 读取 */ }
  getStoredToken(): string | null { /* 从内存读取 */ }
  setAuth(result: AuthResult): void { /* 写入内存 + localStorage */ }
  clearAuth(): void { /* 清除内存 + localStorage */ }
}
```

## 6. AuthContext 设计

### 6.1 状态定义

```typescript
interface AuthState {
  user: User | null;         // 当前用户，null 表示游客
  token: string | null;       // JWT Token（local 模式下为 'local-token'）
  isLoading: boolean;         // 初始化中（从 localStorage 恢复）
  isAuthenticated: boolean;   // 是否已认证（user !== null）
  storageMode: StorageMode;   // 当前存储模式
}
```

### 6.2 AuthContext 职责

```
┌────────────────────────────────────────────┐
│              AuthContext                    │
│                                            │
│  初始化时：                                  │
│  1. 从 localStorage 恢复 user + token       │
│  2. 读取 storage-config                     │
│  3. 初始化对应的 Storage 实例               │
│  4. 如果有 token，调用 /auth/profile 验证    │
│                                            │
│  提供：                                      │
│  - user, token, isAuthenticated            │
│  - login(), register(), logout()            │
│  - switchStorageMode()                      │
│  - storage (IStorage 实例)                   │
└────────────────────────────────────────────┘
```

### 6.3 启动时鉴权流程

```
App 启动
    │
    ▼
┌──────────────────────────────────┐
│ 从 localStorage 读取 user + token │
└──────────────┬───────────────────┘
               │
    ┌──────────┴──────────┐
    │ token !== null      │ token === null
    ▼                     ▼
┌─────────────┐    ┌──────────────┐
│ 调用        │    │ 进入游客模式   │
│ GET /auth/  │    │ user = null  │
│ profile     │    │ storage =     │
│ 验证 token  │    │ localStorage  │
└──────┬──────┘    └──────────────┘
       │
  ┌────┴────┐
  │ 成功    │ 失败 (401)
  ▼         ▼
┌────────┐ ┌──────────────┐
│ user   │ │ 清空 token   │
│ 已设置 │ │ 进入游客模式   │
└────────┘ └──────────────┘
```

### 7.2 退出登录处理

```typescript
async function logout() {
  // 1. 清除认证信息
  storage.auth.clearAuth();

  // 2. 询问是否保留本地数据
  const keepLocal = confirm('退出后本地数据将保留，是否保留？');

  if (keepLocal) {
    // 3a. 切换到本地模式，保留 IndexedDB 数据
    await switchStorageMode({ mode: 'local' });
    navigate('/tasks/my-day');
  } else {
    // 3b. 清空 IndexedDB，跳转到登录页
    await clearLocalDatabase();
    navigate('/login');
  }
}
```

## 8. 无后端模式（local）下的登录页处理

当 `storage.mode === 'local'` 时：

| 页面 | 行为 |
|------|------|
| `/login` | 显示登录表单，但内部调用 `LocalAuthStorage.login()`，生成虚拟用户，无网络请求。表单简化为仅需姓名（或直接跳过）。 |
| `/register` | 显示注册表单，调用 `LocalAuthStorage.register()`，无需网络请求。 |

设计意图：在 local 模式下，"登录"实际是给当前设备设置一个显示名称，用于游客场景下的数据归属标记。

## 10. Auth Guard（路由保护）

```typescript
// ProtectedRoute：当 storage.mode === 'remote' 时，需要 token 才可访问
// 否则（local 模式），所有路由均可访问

function ProtectedRoute({ children }: { children: React.ReactNode }) {
  const { isAuthenticated, storageMode } = useAuth();

  // local 模式下不需要认证
  if (storageMode === 'local') {
    return <>{children}</>;
  }

  // remote 模式下需要 token
  if (!isAuthenticated) {
    return <Navigate to="/login" replace />;
  }

  return <>{children}</>;
}
```
