# ADR-004：Sync V1 不使用 CRDT

- 状态：接受
- 日期：2026-10-21

## 背景

首版仅支持单用户私有清单，没有多人实时共同编辑。待办字段大多是独立标量，CRDT 的
复杂度和存储成本无法带来对应收益。

## 决策

服务端有序、字段级 last-accepted-write-wins：

- 不同字段的修改合并。
- 同字段按服务端接收顺序决定最后值。
- 删除优先，恢复必须显式。
- 保留 change log 供诊断与恢复。

## 后果

离线很久的两台设备同时改同一标题时，较晚上传者覆盖较早上传者；这是可接受的已知语义。
如果未来出现协同需求，再单独评估 CRDT。
