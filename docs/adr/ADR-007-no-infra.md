# ADR-007：首期不接 Redis、消息队列或常驻 WebSocket

- 状态：接受
- 日期：2026-10-21

## 决策

单 Axum 进程 + PostgreSQL 即可支撑首期单用户同步：

- 账号级串行通过 `SELECT ... FOR UPDATE` 实现。
- 客户端前台低频轮询（30–60 秒）与变更后防抖推送。
- 正确性不依赖 WebSocket；后续可增加“有新变更”提示，但仍走增量 API。

## 原因

引入 Redis/Kafka/常驻连接会扩大部署、监控和故障面，而当前负载与实时性要求不需要。
Docker Compose 应能在一台小机器启动完整服务。

## 触发重评的条件

- 多账号高并发同步成为瓶颈。
- 需要近实时协同。
- 变更日志查询或保留策略需要外部分层存储。
